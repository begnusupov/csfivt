# Турнир по бильярду · Пикем

Сайт турнира (double elimination, 10 игроков, 18–19 партий) с пикемом в стиле CS Major.

- **Сетка** — верхняя и нижняя сетки, результаты, проценты «кто за кого» после начала матча.
- **Мой пикем** — прогноз на каждый матч (+1…+5 очков) и прогноз на турнир: чемпион (5), топ-4 (по 1), вылет с 0–2 (по 1).
- **Таблица** — итоговая таблица пикема.
- **Организатор** — ввод результатов, закрытие приёма прогнозов, сброс паролей.

## Устройство

- Фронтенд: статические `index.html`, `style.css`, `app.js` (без сборки и зависимостей), хостинг — GitHub Pages.
- Бэкенд: Supabase (Postgres). Схема и вся логика — `supabase/schema.sql`.
  Таблицы закрыты RLS, браузер вызывает только RPC-функции (`login`, `get_state`, `save_pick`, …).
  Пароли хранятся в виде bcrypt-хэшей, вход выдаёт токен сессии (90 дней).
- `config.js` — URL проекта и публичный anon-ключ.

## Деплой

Содержимое этой папки копируется в корень ветки `gh-pages`.
